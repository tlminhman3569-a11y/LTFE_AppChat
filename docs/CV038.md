```ts
import { recentConversations } from './fixtures/conversations'
import { rooms } from './fixtures/rooms'
import { loadRoom as loadRoomMock } from './fixtures/mockServices'
import { createConversationKey } from './utils/conversationKey'

const keyNguoi = createConversationKey({ kind: 'people', name: 'minh_an' })
const keyPhong = createConversationKey({ kind: 'room', name: 'minh_an' })
```

Đường dẫn import trong ví dụ tính từ `frontend/src` và cần điều chỉnh theo vị trí file JSX/TSX thực tế. `mockServices` **chỉ dùng khi dựng UI/kiểm tra mẫu**. API thật phải thông qua `services/roomsApi.ts`/`services/usersApi.ts` sau khi CV tích hợp thực hiện.

## 3. Callback thống nhất

- **Mẫn:** Sidebar gửi `onSelectConversation({ kind, name })`. Mẫn giữ state chọn hội thoại; tạo khóa bằng `createConversationKey`, truyền tham chiếu sang ChatPage của Kiệt. Không ghép theo `name` đơn lẻ.
- **Kiệt:** Header chat khi loại `room` nhận `RoomActionsProps`/`MemberListProps` của Khôi. `onRequestLeave({kind:'room', name})` mở dialog và cảnh báo nháp; chỉ sau `OUT_ROOM` xác nhận thành công mới xóa nháp/khóa gửi. `onShowMembers` và `onRefresh` chỉ đọc phòng qua duy nhất `roomsApi.loadRoom`.
- **Khôi:** Tìm người theo tập gần đây hoặc `checkExists` tên chính xác; gõ tên phòng không tự JOIN. Lấy owner/members từ metadata có cờ xác nhận, không coi danh sách gần đây là quyền thành viên.
