# CV06 — Kiểm tra API ngày 11/11/2026

API của thầy dùng WebSocket tại `wss://chat.longapp.io.vn/chat/chat`. Hai lượt gọi dưới đây dùng cùng một socket. `login` đã mở kết nối và chỉ trả thành công khi phản hồi có mã phiên hợp lệ.

## Phản hồi quan sát được

Các ví dụ giữ cấu trúc và kiểu dữ liệu đã quan sát. Tên, mật khẩu, mã phiên và thời gian bên dưới đều là giá trị minh họa.

**LOGIN**

```json
{"action":"onchat","data":{"event":"LOGIN","data":{"user":"<tai-khoan-thu>","pass":"<da-che>"}}}
```

```json
{"status":"success","event":"LOGIN","data":{"RE_LOGIN_CODE":"<da-che>"}}
```

**GET_USER_LIST**

```json
{"action":"onchat","data":{"event":"GET_USER_LIST","data":{}}}
```

```json
{"event":"GET_USER_LIST","status":"success","data":[{"name":"phong_mau","type":1,"actionTime":"<chuoi-thoi-gian>"}]}
```

Lượt thử nhận 3 mục, đều có `name` và `actionTime` dạng chuỗi, `type` dạng số. Cả ba có `type: 1`. Theo tài liệu dự án, `0` là người dùng và `1` là phòng. Lượt thử này chưa có mục `type: 0` để đối chiếu. `GET_USER_LIST` trả danh sách hội thoại gần đây. Múi giờ của `actionTime` chưa được xác minh.

## Dùng adapter chung

Ví dụ import từ một file nằm trong `frontend/src/services/`. Phần đăng nhập chạy ở luồng xác thực. Phần lấy danh sách chạy sau khi đã xác thực trên chính kết nối đó.

```ts
import { login } from './authApi'
import { socketClient } from './socketClient'

const session = await login(username, password)
if (session.status === 'success') {
    const response = await socketClient.request('GET_USER_LIST', {})
    if (response.status === 'success' && Array.isArray(response.data)) {
        // Kiểm tra từng mục rồi chuyển sang kiểu hội thoại nội bộ
    }
}
```

- Khôi dùng `socketClient.request('GET_USER_LIST', {})` trong `usersApi.ts` ở CV42. Kiểm tra `status`, mảng `data` và từng mục `name`, `type`, `actionTime` trước khi cập nhật danh sách. Giữ danh sách cũ nếu tải lại gặp lỗi.
- Kiệt dùng cùng `socketClient` cho lịch sử chat riêng. Đọc phòng qua `roomsApi.loadRoom` của Khôi theo `HOP_DONG.md`. Giữ `SEND_CHAT` theo luồng đối chiếu tin riêng.
- Xử lý lỗi kết nối và timeout khi `request` reject. `wasSent` chỉ cho biết client đã giao yêu cầu cho WebSocket. Với tác vụ ghi đã gửi mà mất phản hồi, kết quả vẫn chưa xác định.
- Giữ mật khẩu và mã phiên ngoài log, mẫu dữ liệu và Git. CV07 sẽ ghép luồng xác thực vào form.
